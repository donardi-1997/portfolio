AI Recruiter es una plataforma desarrollada para automatizar procesos de selección de talento utilizando Inteligencia Artificial Generativa, arquitectura cloud y técnicas de Retrieval Augmented Generation (RAG).

El objetivo del proyecto es reducir el tiempo necesario para analizar hojas de vida y encontrar candidatos adecuados para una vacante específica. La plataforma permite cargar documentos PDF de candidatos, procesar su información mediante modelos de lenguaje avanzados y generar evaluaciones inteligentes basadas en los requisitos de cada posición.

La aplicación está desplegada en AWS utilizando una arquitectura basada en contenedores Docker, servicios administrados y buenas prácticas de seguridad cloud.

¿Cómo funciona?

El sistema recibe las hojas de vida de los candidatos y almacena los documentos utilizando servicios AWS. Posteriormente, la información es procesada mediante extracción de datos, embeddings y búsqueda semántica para construir una base de conocimiento inteligente.

A diferencia de una búsqueda tradicional basada únicamente en palabras clave, AI Recruiter utiliza modelos de lenguaje avanzados para comprender el contexto del candidato, identificar experiencia profesional, habilidades técnicas, certificaciones y generar coincidencias relevantes con una oferta laboral.

Arquitectura del proyecto

  • Frontend: Aplicación web desarrollada con React para gestión de candidatos, visualización de rankings y consulta de resultados generados por IA.
  • Backend: API desarrollada con FastAPI encargada de gestionar autenticación, candidatos, vacantes, procesamiento de información y comunicación con servicios de inteligencia artificial.
  • Amazon Bedrock: Servicio utilizado para integrar modelos de lenguaje capaces de analizar documentos y generar evaluaciones inteligentes.
  • Amazon Bedrock Knowledge Bases: Implementación de arquitectura RAG (Retrieval Augmented Generation) para consultar información almacenada dentro de las hojas de vida.
  • Amazon S3: Almacenamiento seguro de documentos, archivos del proyecto y recursos estáticos.
  • AWS ECS Fargate: Despliegue del frontend y backend mediante contenedores Docker sin administrar servidores.
  • Application Load Balancer: Distribución del tráfico hacia los servicios desplegados en AWS.
  • Amazon Cognito: Gestión de autenticación mediante usuarios, tokens JWT y control de acceso.
  • Route 53 + ACM: Configuración de dominio personalizado, HTTPS y certificados SSL.

Funcionalidades principales

  • Carga y procesamiento automático de hojas de vida en formato PDF.
  • Extracción inteligente de experiencia, habilidades y certificaciones.
  • Consultas mediante lenguaje natural sobre información del candidato.
  • Evaluación automática candidato-vacante utilizando Inteligencia Artificial.
  • Generación de fortalezas, brechas técnicas y nivel de coincidencia.
  • Ranking inteligente de candidatos según requisitos del puesto.
  • Interfaz web responsive accesible desde dispositivos móviles.

Tecnologías utilizadas

Python, FastAPI, React, JavaScript, Docker, AWS ECS Fargate, Amazon Bedrock, Bedrock Knowledge Bases, Amazon S3, Cognito, DynamoDB, Application Load Balancer, Route 53 y AWS Certificate Manager.

Arquitectura Cloud

La solución utiliza una arquitectura moderna basada en servicios cloud:

  • Frontend React desplegado mediante contenedores AWS ECS Fargate.
  • Backend FastAPI preparado para procesamiento mediante APIs REST.
  • Integración con modelos LLM mediante Amazon Bedrock.
  • Sistema RAG utilizando Knowledge Bases para recuperación semántica.
  • Comunicación segura mediante HTTPS y certificados administrados por AWS.

Impacto del proyecto

AI Recruiter demuestra la aplicación práctica de Inteligencia Artificial Generativa en un escenario empresarial real, combinando desarrollo de software tradicional con servicios cloud modernos.

El proyecto integra conceptos actuales de la industria como arquitecturas basadas en contenedores, APIs REST, autenticación segura, búsqueda semántica, modelos de lenguaje y despliegue profesional en AWS.

Esta solución representa una aproximación real a cómo las empresas pueden utilizar Inteligencia Artificial para optimizar procesos de selección de talento, reduciendo tiempos de análisis y mejorando la toma de decisiones.
