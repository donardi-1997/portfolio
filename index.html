AI Recruiter

Plataforma inteligente para análisis y evaluación de candidatos mediante Inteligencia Artificial

AI Recruiter es una plataforma desarrollada para automatizar procesos de selección de talento utilizando Inteligencia Artificial Generativa, arquitectura cloud y técnicas de Retrieval Augmented Generation (RAG).

El objetivo del proyecto es reducir el tiempo necesario para analizar hojas de vida y encontrar candidatos adecuados para una vacante específica. La plataforma permite cargar documentos PDF de candidatos, procesar su información utilizando modelos de lenguaje avanzados y generar evaluaciones basadas en los requisitos de cada posición.

¿Cómo funciona?

El sistema recibe las hojas de vida de los candidatos y las almacena en una arquitectura basada en servicios AWS. Los documentos son procesados mediante embeddings y almacenados en una base de conocimiento para realizar búsquedas semánticas.

A diferencia de una búsqueda tradicional por palabras clave, AI Recruiter utiliza inteligencia artificial para comprender el contexto del candidato, identificando experiencia, habilidades técnicas, certificaciones y coincidencias relevantes con una oferta laboral.

Arquitectura del proyecto

  • Frontend: Interfaz web para gestión de candidatos, carga de CVs y visualización de resultados.
  • Backend: API desarrollada con FastAPI encargada de gestionar autenticación, candidatos, vacantes y comunicación con servicios de inteligencia artificial.
  • Amazon Bedrock: Utilizado para integrar modelos de lenguaje capaces de analizar información de candidatos y generar evaluaciones inteligentes.
  • Amazon Bedrock Knowledge Bases: Implementado para crear un sistema RAG que permite consultar información contenida en los documentos cargados.
  • Amazon S3: Almacenamiento seguro de documentos y recursos del proyecto.
  • AWS ECS Fargate: Despliegue del backend y frontend utilizando contenedores sin administrar servidores.
  • Application Load Balancer: Distribución del tráfico hacia los servicios desplegados en AWS.
  • Amazon Cognito: Gestión de autenticación y seguridad de usuarios mediante tokens JWT.
  • CloudFront + Route 53 + ACM: Publicación del proyecto utilizando dominio personalizado, HTTPS y distribución global de contenido.

Funcionalidades principales

  • Carga y procesamiento de hojas de vida en formato PDF.
  • Extracción inteligente de información relevante del candidato.
  • Consultas mediante lenguaje natural sobre experiencia y habilidades.
  • Evaluación automática candidato-vacante.
  • Generación de fortalezas, brechas técnicas y nivel de coincidencia.
  • Ranking inteligente de candidatos según requisitos del puesto.

Tecnologías utilizadas

Python, FastAPI, React, JavaScript, Docker, AWS ECS Fargate, Amazon Bedrock, Knowledge Bases, S3, Cognito, DynamoDB, Application Load Balancer, CloudFront, Route 53 y AWS Certificate Manager.

Impacto del proyecto

AI Recruiter demuestra la aplicación práctica de Inteligencia Artificial Generativa en un escenario empresarial real, combinando desarrollo de software tradicional con servicios cloud modernos.

El proyecto integra conceptos actuales de la industria como arquitecturas serverless, contenedores, APIs REST, autenticación segura, búsqueda semántica y modelos de lenguaje, mostrando la capacidad de diseñar y desplegar soluciones completas en AWS.
